# Studien-Dashboard (Python Prototyp)

Eine Desktop-Anwendung zur einfachen Verwaltung des eigenen Studiums.

## Hauptfunktionen
- **Notenverwaltung:** Erfassung von Prüfungsleistungen und automatische Berechnung des Semester- und Gesamtdurchschnitts.
- **Modulfortschritt:** Übersicht über laufende Module, Kapitelstände und visuelle Fortschrittsbalken.
- **Lernzeiterfassung:** Erfassung der täglichen Lernstunden mit visueller Auswertung über ein Matplotlib-Balkendiagramm.
- **ToDo-Liste:** Einfache Aufgabenverwaltung zum Hinzufügen, Abhaken und Löschen von ToDos.
- **Datenhaltung:** Automatische Speicherung und Wiederherstellung des Gesamtzustands über eine lokale JSON-Datei.
